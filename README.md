# 记事本软件使用教程

这是一个简单的记事本软件使用教程项目。

## 项目介绍

本教程将教你如何使用 Windows 自带的记事本软件进行基本的文本编辑。

## 目录

- [基础功能](#基础功能)
- [高级功能](#高级功能)
- [快捷键](#快捷键)

## 基础功能

### 1. 打开记事本

- 按下 `Win + R` 键打开运行对话框
- 输入 `notepad` 并按回车
- 记事本程序将启动

### 2. 新建文件

- 点击 `文件` > `新建`
- 或使用快捷键 `Ctrl + N`

### 3. 保存文件

- 点击 `文件` > `保存`
- 或使用快捷键 `Ctrl + S`
- 选择保存位置并输入文件名

## 高级功能

### 1. 查找和替换

- 点击 `编辑` > `查找`
- 或使用快捷键 `Ctrl + F`

### 2. 打印文档

- 点击 `文件` > `打印`
- 或使用快捷键 `Ctrl + P`

## 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + N | 新建文件 |
| Ctrl + O | 打开文件 |
| Ctrl + S | 保存文件 |
| Ctrl + P | 打印 |
| Ctrl + F | 查找 |
| Ctrl + H | 替换 |
